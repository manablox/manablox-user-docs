# Changelog

## 0.50.0 - unreleased

The first release of the user guide, for Manablox 0.50.0, at https://docs.manablox.io.

- **Getting started**: create a CMS with `manablox create`, sign in, make a first page and show it on a website.
- **Your project**: the files, everyday commands, `.env`, the database, uploads, mail, logs, content types, workflows and webhooks in code, and the premium plugins and their licenses.
- **The content model, the admin and the designer**: every screen of the admin, and designing a website without code.
- **Building a website**: the starter website, the SDK, GraphQL, REST, preview and the visual editor, caching and Nuxt.
- **Extending, going live and help**: plugins, field types, workflow actions and hooks; servers, domains, updates, backups and security; the `manablox` command reference, common problems and questions.
- A production image, `ghcr.io/manablox/user-docs`, the site behind nginx.
