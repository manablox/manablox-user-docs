---
title: "Styling one block"
description: "Give a single block on a page its own background, spacing, alignment or variant right in the content editor, without changing the block design for every page."
---

A block design applies to every block of that type. Sometimes one block on one page should stand out: a colored band, more space around it, centered text. You do that in the content editor, and it changes only that block.

This works in spaces that are [designed sites](./index.md).

## Where to find it

- **In the visual editor:** click **Visual** in the document's header, select a block on the canvas, and open **Style this block** in the panel.
- **In the form editor:** each block in a Blocks or Block field has a **Style this block** section you can open. A block with its own style shows a **customized** badge.

## What you can change

| Setting | What it does |
| --- | --- |
| **Variant** | Which variant of the block design this block uses. Shown when the design has more than one |
| **Background** | A color from the theme, optionally see-through |
| **Background image** | **Choose an image**, then its position (**Center**, **Top**, **Bottom**, **Left**, **Right**), its size (**Cover**, **Contain**, **Original size**) and whether to **Repeat the image** |
| **Space above and below**, **Space left and right** | Padding, from the theme's spacing steps |
| **Gap between elements** | Space between the block's elements |
| **Text alignment** | **Design default**, **Left**, **Center** or **Right** |
| **Width** | **Design default**, **Contained** or **Full width** |
| **Hide on** | Hide the block on **Desktop**, **Tablet** or **Mobile** |

The style belongs to the document: it is saved with it, published with it and kept in its versions. **Reset** takes the block back to its design.

To change how every block of this type looks, click **Edit block design**; it opens the [block designer](./blocks.md).

## Drafts of designs in the visual editor

The visual editor of a designed site shows your page on the real site design. By default it uses the published designs. Switch on **Draft designs** in its toolbar to see design changes that are not published yet.

If the canvas says "The site has no address yet", the site process is not known to the admin; see [Before you start](./index.md#before-you-start).
